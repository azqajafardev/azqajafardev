## Hello, I'm Azqa 👋

I'm a Software Engineering graduate and AI Developer based in Pakistan. I build practical AI applications around a simple principle: an answer is more useful when you can trace its evidence, understand its limitations, and rely on the engineering behind it.

My work spans retrieval-augmented generation, agent workflows, backend APIs, and applied deep learning. I enjoy taking an idea from experiment to a usable interface—with source citations, thoughtful failure handling, and clear documentation.

## Selected projects

### [Agentic RAG Research Assistant](https://github.com/azqajafardev/agentic-rag-research-assistant)

A research assistant for querying uploaded PDFs with evidence-backed answers and source citations. Built with **Python, FastAPI, Streamlit, ChromaDB, LangChain/LangGraph, and local embeddings**. The project explores document ingestion, retrieval, and agent-guided reasoning in a complete application workflow.

### Enterprise AI Security Assistant

An AI-assisted security workflow for monitoring, investigation, and reporting. Combines **Python APIs, agent orchestration, RAG, and a Flutter interface** to help organize security signals and make findings easier to inspect.

### 3D Alzheimer's Classification Research

A Software Engineering research project exploring **3D medical-image classification**, deep learning, and evaluation of model behavior across brain-imaging views.

### UniGuide AI

A university-focused assistant that uses **NLP and retrieval** to answer questions about admissions, courses, departments, and institutional information.
